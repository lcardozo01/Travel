For Solar System bodies, the calculator computes the full 3D separation ( Δx² + Δy² + Δz² ) using a simplified inclined Keplerian orbit model. The plotted route is an educational straight-line course from the departure location at the selected date to the destination’s projected location at estimated Solar-frame arrival. It does not solve a true moving-target intercept or model gravity, propulsion mass, hazards, or navigation.
